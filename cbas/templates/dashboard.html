Arquitectura Híbrida Desacoplada (Storage Decoupling)

Plano de Datos (Dropbox Core Storage)

Los archivos binarios reales (Word, PDF, CSV) viajan directo a la nube de Dropbox sobre infraestructura Magic Pocket y cifrado AES-256. El servidor backend jamás almacena archivos pesados.

Plano de Control (Backend SQLite)

El servidor local solo guarda metadatos livianos de telemetría: hashes SHA-256 de 4 MB, identificadores rev, IP, usuario de SO y fechas UTC para auditoría ISO/IEC 27001.
